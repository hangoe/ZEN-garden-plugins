# ZEN-garden-plugins

Plug-ins, extensions, and add-ons for ZEN-garden. For installation and 
usage instructions, please see the [ReadTheDocs](https://zen-garden-plugin.readthedocs.io/en/latest/)

## MGA plugin

This fork adds the `mga` plugin (`zen_garden_plugins/mga`): exploration of a
model's near-optimal space, either via classical weighted MGA re-solves or
via the ORACLE algorithm (certified inner/outer polytope approximations).
Requirements, configuration, and outputs are documented in
[docs/files/available_plugins/mga/mga.rst](docs/files/available_plugins/mga/mga.rst).
